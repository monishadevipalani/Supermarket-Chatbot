# 🛒 Supermarket Chatbot

A simple and interactive **Supermarket Chatbot** developed using **Python and Flask**. This chatbot helps supermarket customers by answering common queries and providing useful information through a user-friendly web interface.

## 📌 Project Overview

The Supermarket Chatbot is a web-based chatbot application that allows customers to interact with a virtual assistant. Users can enter their questions or messages, and the chatbot provides appropriate responses based on predefined rules.

This project demonstrates the use of **Python Flask** for backend development and **HTML, CSS, and JavaScript** for creating the frontend interface.

## ✨ Features

- 🤖 Interactive chatbot interface
- 👋 Greets customers
- 🛍️ Provides supermarket-related information
- 💬 Responds to customer queries
- 🏪 Provides basic supermarket services information
- 🌐 Web-based user interface
- 📱 Simple and user-friendly design
- ⚡ Fast responses using predefined chatbot rules

## 🛠️ Technologies Used

- 🐍 Python
- 🌐 Flask
- 📄 HTML
- 🎨 CSS
- ⚡ JavaScript
